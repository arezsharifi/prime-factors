# Prime Factorization in Python

A simple Python program that finds the prime factors of a given number using basic mathematical operations and loops.

## 📌 About the Project

This project is a beginner-friendly Python implementation of prime factorization.

The program:
- Takes an integer input from the user.
- Finds the prime factors of the given number.
- Stores the factors in a list.
- Displays the factors in sorted order.

## 🛠️ Technologies Used

- Python 3
- Math module
